# Angrier Jordan Developer Acceleration Pack v1

Purpose: reduce Codex development time, duplicate implementation, and rework by converting the product spec into machine-readable contracts and reusable foundations.

## Included
- Master Command Registry: **180 commands/interactions**
- Master Settings Schema: **136 live-config definitions**
- Capability Matrix
- Feature Dependency Graph
- Prisma/PostgreSQL starter schema
- Shared engine contracts + shared TypeScript interfaces
- Test fixtures + **68 acceptance tests**
- Server setup/bootstrap contract
- Cost-optimized implementation phases
- `.env.example`, local PostgreSQL Docker Compose, CI and package script plan
- Codex execution contract/start prompt
- Remaining authored content pack: **2985 entries**

## Important
This pack does not replace the canonical build spec. It operationalizes it. When a conflict exists, canonical spec wins unless a newer explicit owner decision supersedes it.

## Command registration budget
The registry now distinguishes preferred UX invocations from actual Discord `registration_path` values. The grouped plan uses **57 top-level chat-input commands**, leaving headroom for future additions while keeping `/play` and high-frequency commands easy to reach.
