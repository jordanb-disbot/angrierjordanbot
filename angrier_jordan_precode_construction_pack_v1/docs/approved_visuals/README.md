# Approved Runtime Visual References

`wyr_runtime_standard.png` is the owner-approved visual reference for the production bot UI as of 2026-09-21.

Locked visual rules carried into implementation:
- Discord sender name is **Angrier Jordan**.
- Do not repeat an Angrier Jordan wordmark inside ordinary feature cards.
- Use only the approved style-guide typography (Poppins for UI/body; Cinzel for restrained display headings).
- Core palette remains Midnight/Navy with Teal/Gold and approved support accents.
- Feature accents may vary by feature while remaining within the same visual system.
- Human mascot appears in the Discord avatar/logo treatment; do not place a large mascot portrait behind normal feature content.
- Feature-card backgrounds may use a subdued lounge/chair scene or remain mostly clean/blank.
- No prominent red Angrier Jordan neon wall sign.
- Desktop/mobile hierarchy should remain Discord-native and legible.

The reference board is a review reference, not a runtime asset to send directly to Discord. Runtime cards remain deterministic render output.
