# Casino / Profiles presentation audit

These findings concern fixture attachments generated by actual runtime renderers. They do not certify live Discord acceptance or approve Gate B.

- Chair Pot and lottery announcement attachments consume persisted settlement values through `apps/bot/src/discord/casino-announcements.ts`; no simulated settlement is executed by the fixture script.
- Major casino win uses the settled round attachment from `casino-coordinator.ts`, including exact stake and returned amount. Play Again and Rules remain Discord-native controls outside the image.
- Major record uses the current `/records` attachment with All time / This month selector; it is not represented as an automatic record announcement.
- Weekly Spotlight uses frozen awards with resolved identities, ties, no-qualifier states, and the permanent Triple Threat label. Its synthetic fixture avatars are explicitly labeled placeholders.
- Profile summary and Edit Showcase remain unchanged native Discord embeds/controls, with owner-only edits and private follow-ups. No redesigned profile screenshot is claimed.

## Objective defects fixed

Unbroken member names could overflow casino, records and Spotlight panels. These renderers now use the shared bounded text-layout helper. Long payout values previously reduced the font toward unreadable sizes; the exact integer now uses readable 24px text with its currency unit on a separate line. Spotlight server-total panels now grow with wrapped values rather than overflow at large totals.

The approved packaged lounge shell, navy/teal/brass palette, Space Grotesk headings and Inter body remain intact. Approved Line, Race, Fight and standard-window code and immutable snapshots are untouched by this workstream.

## Review scope and limitations

`review-items.json` describes 10 fixture states and links 20 desktop/mobile attachment PNGs. Mobile is the real attachment resized to 360px; it is not a claim about Discord client layout. Native controls are described but not fabricated inside screenshots. Owner review should assess the hierarchy of the unchanged visual family and the long multi-winner Spotlight card at mobile size. A different compact/tiled co-winner design would be a product choice, so none was invented here.

## Validation

Eight targeted adapter/renderer tests passed. Ten metadata entries and twenty PNG dimensions validated. All ten mobile fixtures visually inspected after regeneration, including long names, exact BIGINT values, multiple winners and empty states; no clipping found. Desktop images use the same runtime SVG at 440px, mobile 360px. Full workspace and integration validation is reported by the coordinating review.
