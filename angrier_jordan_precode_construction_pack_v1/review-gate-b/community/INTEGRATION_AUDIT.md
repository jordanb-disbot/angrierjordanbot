# Community / Chairisms / Superlatives engineering audit

Gate B remains pending owner review. No production deployment, feature enablement, live Discord acceptance, or runtime AI art occurred.

## Integration findings

- Community commands route through the shared feature gate and fresh member/channel eligibility. Community management uses the shared `community.manage` capability (Chaise Lounge / Throne). Giveaway entry confirmation binds the current member and exact displayed fee.
- Community repositories use shared atomic operation receipts, Session, Timer, Voting, Ledger, escrow, Audit, and durable Delivery engines. Anonymous authors and ballots stay absent from public projections; hidden poll results remain hidden until closure. Declined AMA projections replace the question with an unavailable notice.
- Chairisms check fresh source/output permissions, ordinary member-access visibility, staff/excluded channels and categories, source/message type, and selected reply/image. Controls are member-bound. Only allowlisted bounded Discord image bytes reach the renderer. Delivery revalidates immediately before send and saves metadata only after confirmed delivery; finalized jobs discard the temporary text/image snapshot.
- The source registry, presentation matrix, generated settings, and capabilities match these implemented routes. Community and Chairisms feature defaults remain false. Fixed Superlative durations/finalist count remain immutable. Family persistence changes introduced no domain-contract dependency in these feature repositories.

## Objective defects fixed

- Community publication, advancement, refresh, and sweep now obey the server feature flag. Disabled recovery keeps its durable pending obligations without issuing new public posts or progressing settlement. The central runtime also gates these entry points on its runtime enable switch.
- Wide-glyph text and long unbroken names now use shared width-aware layout bounds inside the existing approved frames. Chairism names truncate visibly; full quote text continues vertically. Community content remains available in Details when the fixed card overflows.
- A Superlative season with no nominations no longer claims winners or awarded badges. Long truncated category/winner text signals Details.
- Closed giveaway cards/transcripts show the actual number of selected winners, not the configured maximum, with correct singular counts. Empty draws claim no prizes; custom draws still awaiting organizer fulfillment no longer claim that rewards were recorded as completed.

- Declined, reviewing, and fulfillment-pending statuses use the approved warm attention color rather than emerald success.
