# Gate B — deterministic family review fixtures

These are actual runtime-renderer PNG outputs for marriage voting, divorce, inheritance and a sealed self-auction. Alex Morgan and Sam Rivera are fictional fixture names; their deterministic initials avatars are fixture avatars. Production supplies the current Discord avatars and stored event values.

The render family inherits the approved lounge/event frame, existing art, Space Grotesk headings and Inter body. No generated runtime artwork or new brand is introduced. Discord's actual buttons are supplied by the coordinator, outside the raster image. Marriage voting controls freeze at close and View Family remains available; open auctions expose a private bid modal.

Run `node packages/features-family/review/render.mjs` after the coordinated runtime build. Gate B approval remains pending; these files do not enable any production feature.
