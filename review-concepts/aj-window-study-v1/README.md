# Angrier Jordan — standalone window study

This is a review-only concept board, not a production implementation. It contains one Line readiness state in purple and one basic Would You Rather question state in teal/gold. All names, counts and timers are fixtures.

Permanent brand elements: midnight/deep-teal foundation; realistic leather, dark wood and brass; warm lounge lighting and foliage; inset translucent windows, fine borders and gold corner details; Space Grotesk headings and Inter body text; Angrier Jordan sender identity.

Feature/state elements: Line purple border, icon, readiness badge, timer rail and primary action; game gold/teal option accents; labels, counts and controls appropriate to the displayed state. Accent skins change without replacing the underlying room or materials.

The custom button finishes illustrate the desired visual system. This mockup makes no claim that Discord native controls can accept arbitrary gradients or fonts.

Files: window-study.png is the review image; window-study.svg embeds its background; render-concept.mjs preserves the layout. No production feature consumes this concept directory. Production Race/Fight work and Railway readiness remain paused for owner review.

## Fixed artwork provenance

The lounge is a previously prepared fixed background generated with the built-in imagegen tool, guided by the two owner-supplied September 21 boards. This concept uses that packaged artwork; no generation runs during rendering. All typography, state text, icons, panels and controls are rendered deterministically in code.
